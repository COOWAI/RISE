# Security Policy

## Supported versions

No public version is currently supported because `0.1.0` has not yet been released. After release, security fixes
will be applied to the latest published `0.1.x` version. Development snapshots are supported on a best-effort basis
and should not be treated as production deployments.

## Reporting a vulnerability

Use GitHub Private Vulnerability Reporting from the repository's **Security** tab and select **Report a
vulnerability**. This keeps the report confidential while maintainers investigate it. Do not open a public issue for
a suspected vulnerability, and do not include credentials, private datasets, or sensitive infrastructure details.

Include the affected revision or version, impact, reproduction steps, and any suggested mitigation. Maintainers will
acknowledge the report through the private report, assess its scope, coordinate a fix when warranted, and publish an
advisory after users have a reasonable opportunity to update.

## Research-code scope

RISE is research software. Model outputs, training artifacts, and evaluation results must not be treated as safety
assurances for a deployed vehicle or other safety-critical system.
